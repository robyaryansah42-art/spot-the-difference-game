A spot-the-difference game for the make.fun bounty
[best-spot-the-difference-game-20261121-0451](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451):
two near-identical pictures side by side, find the differences, markers on
the ones found, a counter of how many remain. Three original hand-drawn
scenes, 7 differences each, hints, a timer, and a score chase — all art
drawn in code, no borrowed images.

## Play it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
